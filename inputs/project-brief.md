# AI 여행 플래너

## 프로젝트 목적
사용자가 여행지와 기간을 입력하면 취향에 맞는 여행 일정을 제안한다.

## 주요 사용자
- 자유여행을 준비하는 직장인
- 짧은 시간 안에 여행 일정을 만들고 싶은 사용자

## 핵심 기능
- 여행지 검색
- AI 일정 생성
- 맛집과 관광지 추천
- 여행 일정 저장

## 기술 스택
- Next.js
- FastAPI
- PostgreSQL

## 프로젝트 원칙
- 추천 결과에는 선택 이유를 표시한다.
- 개인정보는 필요한 범위에서만 사용한다.
- 사용자가 일정을 직접 수정할 수 있어야 한다.
